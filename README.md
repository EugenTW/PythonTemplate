requirements.txt → Lists all dependencies.  
main.py → Entry point of the application.  
feature.py → Implements reusable features.  
build.py → Automates packaging for Windows and Linux.  

Packaging Instructions:  
In PyCharm terminal:  
Windows: Activate .venv and run 'python scripts/build.py'.  
WSL: Activate .venv and run 'python scripts/build.py'.
